# 언스크롤 · 1차 프로토타입

릴스, 쇼츠처럼 끝없이 넘기게 되는 사용을 하루 1분 돌아보고, 생성형 AI와 그 계기를 찾는 앱의 1차 프로토타입이다.
앱을 막거나 사용 시간을 혼내지 않고, 사용자가 직접 "좋았어요 / 그냥 그래요 / 아쉬워요"를 고른다.

시연에서는 휴대폰 사용 기록 대신 **가상 스크린타임**(`sim.py`)을 쓴다. 세션 길이 비율은 LSApp 공개 데이터 분석 결과를 따랐다.
실제 앱에서는 이 자리에 안드로이드 사용 기록(UsageStatsManager)이 들어간다.

## 바로 써 보기 (시연 링크)

https://jkzk1397.github.io/unscroll/

`docs/` 폴더의 체험판이다. 서버 없이 브라우저 안에서 가상 스크린타임과 모의 AI로 돌아간다. 휴대폰으로 열면 앱 화면처럼 꽉 차게 보인다.


## 2차 고도화 (조사 보고서 반영)

경쟁 앱은 대부분 '막는' 데 집중하고, 생성형 AI는 잠금 해제 문지기 정도로만 쓴다. 언스크롤은 **기록 → 근거 있는 추측 → 내가 고치기 → 계획 메뉴 → 그 계획이 뜨는 알림 → 다음 주 점검**의 고리를 AI로 닫는 데 집중한다.

- 주간 돌아보기: **관찰(코드가 센 숫자)과 AI의 해석을 나눠서** 보여 준다. 추측마다 내가 남긴 기록을 근거로 붙이고, '맞아요 / 일부만 맞아요 / 아니에요, 실은…'으로 고칠 수 있다. 고친 내용은 다음 주 프롬프트에 들어간다.
- 계획: AI가 "그 순간 사실 필요했던 건?"을 한 번 묻고(동기면담식), 답을 반영한 '만약 ~하면, ~한다' 계획 3~4개를 내놓는다. 고르고 내 말로 고친다.
- 숏폼 알림: 주간 돌아보기 때 상태별(심심해서/피곤해서/할 일 미루는 중/재밌어서) 문구를 AI가 미리 써 두고, 알림이 뜰 때는 코드가 고른다. 내 계획과 "왜 지금" 근거(지난 기록)도 함께 보여 준다.
- 홈: 일일 숏폼 시청 시간 꺾은선(어제·평균 비교)에 '아쉬웠던 시간'을 겹쳐 보여 준다. 하루 시계는 바깥 고리 하루, 안쪽 산은 일주일.
- 오늘 돌아보기: 숏폼만 먼저 묻고, 본 내용은 한 탭 태그(웃긴 거/정보/아이돌·덕질/게임/뉴스·이슈/아무거나 뜨는 대로)로 남긴다. 다른 앱은 선택, 건너뛰기 가능.
- 친구: 순위 대신 그룹이 같이 줄인 시간과 익명 평균. 시청 시간과 이유는 공유하지 않는다.
- AI 연결: 설정에서 내 Gemini API 키를 넣으면(이 기기 브라우저에만 저장) 체험판도 실제 AI로 돈다. 서버 실행 시에는 `.env` 키로 `/api/llm`을 거친다. 키가 없으면 모의 AI.
- AI 답 확인: 계기 목록 밖, 없는 기록 번호, 근거 3개 미만, 숫자·진단 표현이 든 추측과 계획은 화면에 나오지 않는다.

페이퍼 프로토타입의 '시청 영상 목록'과 '친구 중 몇 번째'는 보고서 판단에 따라 바꿨다. 시청 기록은 공식 API로 가져올 수 없고(유튜브 watchHistory 2016년 폐지) 화면 글자를 읽으면 Play 정책·민감정보 부담이 크며, 순위는 이미 다른 앱에 있고 '좋았던 시청'까지 줄이라는 압박이 된다.


## 생성형 AI가 하는 일 (3차)

| 단계 | AI가 하는 일 | 화면 | 코드가 확인하는 것 |
|---|---|---|---|
| 듣기 | 자유롭게 말하거나 쓴 문장(음성 입력 가능)을 기록별 평가와 이유로 정리 | 오늘 돌아보기 > 말로 한 번에 하기 | 없는 기록 번호, 평가 형식, 힘든 감정 표현은 AI에 보내지 않음 |
| 짐작 | 아쉬웠던 이유를 계기 6개로 묶어 근거와 함께 추측 | 이번 주 돌아보기 | 계기 목록 밖, 근거 3개 미만, 숫자·진단 표현 |
| 해석 | 앱이 센 관찰을 이어 한 문장으로 해석 | 이번 주 돌아보기 > AI의 해석 | 관찰에 없는 숫자, 진단 표현 |
| 함께 정하기 | 그 순간 필요했던 것을 묻는 질문, 답을 반영한 만약-그러면 계획 | 다음 주 계획 | 형식, 금지 표현 |
| 다시 보기 | 지난 계획이 통했는지 앱이 센 숫자를 보고 평가하고, 유지/고치기/바꾸기 제안 | 이번 주 돌아보기 > 지난주 계획 점검 | 숫자를 쓰지 않음, 고친 계획 형식 |
| 묻고 답하기 | 내 기록만 근거로 질문에 답하고 근거 기록을 붙임 | 홈 > 기록에게 묻기 | 진단 표현, 길이 |
| 말 걸기 | 상태별 알림 문구와 공유 카드 한 줄을 고른 말투로 씀 | 숏폼 알림, 공유 카드 | 길이, 금지 표현 |

- **다음 주의 나 (선택 탭)**: 다음 주 목표를 말하면 AI가 목표 한 줄, 앱이 잴 기준(밤 12시~새벽 5시 숏폼, 하루 평균, 아쉬운 횟수, 앱별 시간, 멈춤 도장 중 하나), 다음 주의 나에게 쓰는 편지로 정리한다. 편지는 일주일 봉인되고, 일주일 뒤 앱이 잰 결과와 함께 열린다. 'AI가 상상한 일주일 뒤의 나'와 대화할 수 있다(미래를 단정하지 않도록 지시). AI의 돌아보기가 앱이 잰 결과와 반대로 말하면(늘었는데 '줄었다') 걸러낸다.
- 설정 > AI 말투: 다정하게 / 담백하게 / 친구처럼
- 설정 > AI가 한 일 보기: 보낸 내용, 받은 답, 검사 결과(통과, 걸러냄, 모의 AI 사용)를 볼 수 있다
- 설정 > 시연 > 일주일 넘기기: 계획을 지킨 일주일 뒤의 가상 기록을 만들어 '지난 계획 점검'을 시연한다
- 숫자는 모두 앱 코드가 세고, AI는 문장만 쓴다. AI 답이 검사를 통과하지 못하면 모의 AI(정해 둔 규칙과 문장)로 대신한다

## 실행 (서버 + 실제 AI)

```bash
pip install -r requirements.txt
python server.py
```

- 노트북: 브라우저에서 http://localhost:8000 (휴대폰 모양 틀로 보임)
- 휴대폰: 노트북과 같은 와이파이에서 http://<노트북 IP>:8000 (전체 화면 앱처럼 보임)
- 처음부터 다시 보려면 앱의 설정 > "처음부터 다시"

## 화면 흐름

1. 시작: 이름 → 사용 기록 연결(가상 권한 창) → 지난 7일 기록 불러오기 → 일주일 목표(며칠 돌아볼지) → 알림 시간
2. 홈: 연속 기록, 오늘 폰 사용과 그중 숏폼, 내 계획, 하루 시계
3. 오늘 돌아보기: 10분 넘게 쓴 앱마다 좋았어요/그냥 그래요/아쉬워요, 아쉬우면 이유 한마디
4. 이번 주 돌아보기(AI): 하루 시계 → AI가 짐작한 계기와 근거 기록 → 맞아요/아니에요 → 계획 3개 중 고르기 → 알림 시간
5. 친구: 같이 계획 지키기, 응원하기, 초대 코드, 결과 카드(9:16 이미지) 공유
6. 숏폼 알림: 릴스, 쇼츠를 한 번에 정한 시간(10/15/20/30분)보다 오래 보면 보던 화면 위에 알림이 내려와 가린다. "여기서 그만 볼래요"를 누르면 오늘 돌아보기 목록에 그 사용이 추가되고, "5분만 더 볼게요"를 누르면 5분 뒤 다시 알려 준다. 앱을 강제로 막지는 않는다.
   시연에서는 홈의 "시연: 쇼츠 보다가 n분 넘기기" 버튼으로 가상 쇼츠 화면을 연다 (1초가 1분으로 흐름).
   실제 안드로이드에서는 사용 기록 권한으로 지금 열린 앱을 확인하고, "다른 앱 위에 표시" 권한으로 알림 화면을 띄운다.
7. 설정: 알림 시간과 요일(하루 최대 2개), 다음 일주일 알림 미리보기, 친구에게 보여 줄 것, AI 선택, 가상 기록 바꾸기

**하루 시계**: 한 바퀴가 하루 24시간이다. 위가 낮 12시, 아래가 밤 12시이고 아래쪽 반은 밤이라 어둡게 칠했다.
바깥 줄이 오늘, 안쪽으로 갈수록 지난 날이다. 아래 요일을 누르면 그날만 보인다.

친구에게는 유형, 연속 일수, 계획 지킨 날만 보인다. 앱 이름, 사용 시간, 적은 이유는 공유되지 않는다. 친구 목록은 시연용 가상 친구다.

## Input → Processing → Output

| 단계 | 파일 | 하는 일 |
|---|---|---|
| Input | `sim.py`, `static/index.html` | 가상 스크린타임에서 10분 넘게 쓴 앱만 골라 보여 주고, 사용자가 평가와 이유를 남김 |
| Processing | `core.py`, `llm.py` | 아쉬웠던 기록만 고르기 → 이유 20자 제한, 전화번호·이메일 가리기 → 힘든 감정 표현은 AI에 보내지 않음 → 3개 미만이면 AI 안 부름 → AI 호출(최대 2번) → 결과 확인 |
| Output | `static/index.html` | 계기 추측과 근거 기록, 확인 질문, 계획 고르기, 결과 카드 |
| 알림 | `notify.py`, 화면의 설정 탭 | 사용자가 정한 시간에만, 하루 최대 2개. 숫자는 코드가 계산 |
| Test | `test_run.py` | 시험 사례를 돌려 추측이 맞는지, 헛지적·놓침이 있는지 CSV로 저장 |

AI 결과 확인(`core.check_reflect`)에서 막는 것: 6가지 밖의 계기, 없는 기록 번호, 같은 계기가 3개 미만인 추측, 숫자나 진단 표현이 들어간 문장. 틀린 추측은 화면에 보이지 않는다.

## AI 키 넣기

`.env.example`을 복사해 `.env`로 이름을 바꾸고, 쓸 AI의 키 한 줄만 채운다. `.env`는 깃허브에 올리지 않는다.
키가 없으면 "모의 AI"로 화면 흐름만 확인할 수 있다 (실제 AI가 아니라 단어 규칙으로 흉내 냄).

## 시험 세트 자동 실행

```bash
python test_run.py --ai gemini            # 6개 사례 실행, results/ 폴더에 CSV 저장
python test_run.py --ai gemini --repeat 3 # 같은 사례를 3번씩 (일관성 확인)
```

`data/test_cases.json`의 공격 예시 2건은 옆 팀에게 받은 사례로 바꿔 넣는다.

## 파일

- `server.py` 시연 서버 (화면과 AI 처리를 이음)
- `static/index.html` 앱 화면 전체, `static/fonts/` Pretendard 글꼴 (OFL 라이선스)
- `sim.py` 가상 스크린타임 (사용 패턴 3가지)
- `prompts/reflect_v1.txt` 성찰 프롬프트, `prompts/plan_v1.txt` 계획 프롬프트, `data/methods.json` 계획 방법 10가지
- `app.py` AI 결과를 자세히 확인하는 개발용 화면 (Streamlit, `streamlit run app.py`)

- `docs/` GitHub Pages 체험판 (static/index.html과 같은 화면, 서버 없이 동작)

## 3차 고도화: 시연 중심

- 시연용 휴대폰 홈 화면: 숏폼 앱(가상)을 열면 실제 릴스처럼 영상이 넘어가고, 정한 시간이 되면 알림이 화면 전체를 가려요. 알림 전에 홈 버튼(○)을 누르면 금색 도장.
- 멈추고 나면 홈 화면 위에 알림이 내려와요. 좋았어요, 그냥, 아쉬워요를 바로 누르고 이유까지 고르면 오늘 기록에 들어가요.
- 친구 탭: 친구 소식, 그룹 챌린지(밤 12시 넘어서 숏폼 0분), AI가 초안을 써 주는 응원 메시지와 친구 답장. 친구는 모두 가상 인물이에요.
- 노트북 화면 왼쪽(휴대폰에서는 오른쪽 아래 '시연' 버튼)에 시연 순서 버튼 6개.
- 마이크 입력은 뺐어요. 한 줄로 적고 AI에게 맡기기는 접어 두었어요.
- 영상 속 계정, 쇼핑몰, 글은 모두 지어낸 것이에요.
